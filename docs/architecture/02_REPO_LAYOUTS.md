# 02 — Repo Layouts

Repos: `ReCADBench` (public), `recadbench-cad-skills`, `recadbench-strategies`, `recadbench-data`, `recadbench-gt` (all private). See 00_DECISIONS D3.

Conventions: Python ≥3.11, `uv` or pip, `pyproject.toml` per package, `ruff` + `pytest`, root `CLAUDE.md` (templates/) and root `STATUS.md` (checklist of prompts touching that repo). Empty placeholder folders get a `README.md` stating purpose + filling prompt (not `.gitkeep`).

## Repo 1 — `ReCADBench` (public: benchmark code + L1 pins + measurement)

```
recadbench/
  CLAUDE.md  STATUS.md  README.md
  docs/
    architecture/            # this package, unzipped
    adr/                     # 0001-….md
  spec/                      # SOURCE OF TRUTH → pip `recadbench-spec`
    pyproject.toml
    recadbench_spec/
      schemas/               # contracts/*.json
      feature_taxonomy.yaml  # contracts/feature_taxonomy.yaml (package root)
      models.py taxonomy.py cli.py
    tests/
  backends/                  # L1 — pinned external interfaces + adapters (measurement instruments)
    build123d/
      backend.yaml           # pins pzfreo/build123d-mcp version, MCP prefixes, hosts
      install.md             # incl. Termux steps (PoCAD method)
      adapter/               # recad build123d export|extract|set-param|replay|execute-ir
      replays/               # conformance replays (build123d scripts)
    solidcraft/
      backend.yaml           # pins solidcraft release; interface: solidcraft-cli mcp
      install.md  adapter/  replays/   # replays = Solidcraft JSON command scripts
    freecad/
      backend.yaml           # pins the MCP chosen in P4
      install.md  adapter/  replays/
    nx/
      backend.yaml           # interface: cli; allowed_commands: recadbench nx-run cad/*.py
      install.md             # NX version, run_journal.exe path, licence notes
      runner/                # `recadbench nx-run`: runs journal via run_journal.exe, captures log, timeout
      adapter/               # NX Open journals: export, extract (feature tree), set-param (expressions)
      replays/               # NX journals for conformance cases
    conformance/
      ir_cases/              # 10 IR cases with expected volume / faces / feature count (same in every backend)
      run_conformance.py
  dataset/                   # tooling only — NO part data in this public repo
    tools/make_task.py       # runs on evaluator host: recadbench-gt → recadbench-data
    tools/check_public.py    # CI guard: no STL/STEP/PRT/GT files outside synthetic fixtures
  evaluator/                 # pip `recadbench-eval`
    recadbench_eval/
      gate.py align.py deviation.py parsimony.py intent.py topology.py
      editability.py plan_score.py score.py report.py
    golden/                  # pilot parts × {good, lego, faceted, dumb_solid, wrong_dim, snap_everything}
    tests/
  runner/                    # pip `recadbench-run`
    recadbench_run/
      compose.py             # `recadbench compose` → run dir (D6)
      gate_hook.py           # PreToolUse hook + LiteLLM dispatcher check
      render_prompt.py       # system_prompt.md for non-Claude models
      agents/                # claude_agent_sdk.py, litellm_loop.py
      budgets.py artifacts.py finish.py   # finish = post-run extraction + enqueue
  orchestrator/
    experiments/*.yaml  expand.py  queue.py  worker.py
  results/                   # gitignored; synced to Drive
  leaderboard/build.py       # markdown/CSV first; per track and per layer
  .github/workflows/ci.yml
```

## Repo 4 — `recadbench-data` (private, agent-visible inputs)

```
recadbench-data/
  README.md  STATUS.md
  parts/<part_id>/
    input.stl                # the raw scan, byte-identical, scanner frame (ADR 0002)
    task.yaml                # input_kind, scan metadata, budgets
    aux/                     # optional calipers / photos / notes (empty in v1)
  splits/
    dev.txt                  # 10 ids
    test.txt                 # 40 ids (frozen)
  MANIFEST.json              # sha256 per file; generated by make_task
```
Written only by `make_task.py` on the evaluator host. Workers: read-only clone, path via `RECADBENCH_DATA_DIR`. Raw scans are 18–50 MB each: Git LFS or Drive (decide in P6).

## Repo 5 — `recadbench-gt` (private, evaluator host only)

```
recadbench-gt/
  README.md  STATUS.md
  AUTHORING.md               # how to write gt_plan.json, key_dims.yaml, count n_ref, register a scan (P6)
  parts/<part_id>/
    gt.step  gt_native.*  gt_plan.json  key_dims.yaml  meta.yaml
    scan_raw.stl             # the original scan (source of input.stl); sha256 in meta.yaml
    observability_mask.*     # optional, written by the GT-authoring tool
```
Evaluator reads `RECADBENCH_GT_DIR`. Never cloned on workers.

## Repo 2 — `recadbench-cad-skills` (L2)

```
recadbench-cad-skills/
  CLAUDE.md  STATUS.md  README.md
  _shared/
    ir_execution.md          # how to read an RE Plan IR and execute it faithfully (all skillsets include)

    examples/                # IR snippet → journal, one per taxonomy type; past-project excerpts
    LESSONS.md
    MIGRATION_NOTES.md       # P3: original file → new location / dropped; RE-method text forwarded to strategies
  build123d/
    skillset.yaml  skills/  agents/  lib/  examples/  LESSONS.md
```

`none` skillset = no folder; compose injects only `_shared/ir_execution.md` (minimum needed to read the IR) so the baseline measures the bare L1 interface.

## Dependency graph

```
recadbench-spec ◄── retk, strategies (IR authoring, validation)
                ◄── recadbench backends/adapters, evaluator, runner
recadbench-cad-skills: no code dependency on the benchmark (content + lib only); validated by spec CLI in CI
compose reads: strategy.yaml + skillset.yaml + backend.yaml
```

Adapters are invoked as CLI (`recad <b> …`) on the worker host that has the backend; results travel as files. No Python imports across repos except `recadbench-spec`.
