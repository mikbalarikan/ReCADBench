# docs/handover

The handover from the cloud build session (P1–P6, plus P3 and P5 built for review) to a main session on the ASUS
evaluator host. That main session manages the rest of the development until the first benchmark test.

| File | For |
|---|---|
| [HANDOVER.md](HANDOVER.md) | State, decisions, rules, open items, and the definition of done for "ready for the first test" |
| [PROMPTS_v2.md](PROMPTS_v2.md) | Remaining work H0–H9 as self-contained prompts, with the dependency order |
| [MAIN_SESSION_BRIEF.md](MAIN_SESSION_BRIEF.md) | Paste-in text to start the main session |

The private companion, with desktop paths, data provenance and client notes, is
`ReCADBench-gt/HANDOVER_PRIVATE.md`. It is only on the evaluator host.
